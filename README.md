# みんなで作るカルタ プロトタイプ

ユーザが写真と音声を組み合わせてカルタを作成し、遊ぶことができるWebアプリケーション。  
シビックテック講座で出たアイディアのプロトタイプとして。

## 概要
デバイスのカメラとマイクを使用し、独自の札（音声と画像のペア）を即座に作成できます。  
データはブラウザ内のIndexedDBに保存されるため、サーバーへのデータ送信は行われません。

## 機能
- カード作成：写真の撮影・選択、および音声の録音と保存。
- ゲームプレイ：読み札のランダム再生、正誤判定、残り枚数のカウント。
- 状態管理：全カード獲得時のコンプリート表示、データの一括削除。



## 使用方法
1. `ファイル選択`から画像を取り込みます（PCの場合は既存ファイル選択、iOSの場合は新規写真撮影）
2. `録音開始`を押し、読み札を録音します。
3. `保存`でカードを登録します。
4. `読み札を再生`を押し、該当するカードを選択します。
5. 全てのカードを取り終えるとゲームクリアとなります。

## 技術仕様
- 言語：HTML5, CSS3, JavaScript (Vanilla JS)
- 保存先：IndexedDB
- 動作確認済みOS：iOS, Windows (最新のSafari, Chrome推奨)
- 制限：閲覧にはURLパラメータが必要

## 注意事項
- iOS端末では音声再生時にマナーモードを解除して使用してください。
- ブラウザのキャッシュを削除すると、保存されたカードデータも消去されます。
